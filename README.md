# Diwali_wishes

This project is a festive single-page web app that spreads Diwali wishes with a personalized greeting experience. Users can enter their name, watch animated diyas and a glowing festive background, and reveal a digital Diwali card with warm wishes, sweets, and celebration effects.

## Project Overview

The page is designed as a playful Diwali greeting for friends, family, or loved ones. It combines a modern dark-and-gold aesthetic with animated UI elements such as diyas, sparkles, a gift box reveal, and fireworks-inspired visuals to create a joyful celebration atmosphere.

## Features

- Personalized name input for custom messages
- Animated Diwali card and greeting experience
- Gift box opening section with mithai-themed visuals
- Fireworks and sky-lighting celebration mode
- Responsive design for desktops and mobile devices
- Built using plain HTML, CSS, and JavaScript

## How to Use

1. Open the file `Happy Diwali 🪔.html` in any modern web browser.
2. Type a name in the input field.
3. Click the button to light the diyas and view the greeting.
4. Explore the animated card and festive celebration sections.

This project is ideal for sharing a cheerful Diwali message in a fun, interactive, and visually rich format.
